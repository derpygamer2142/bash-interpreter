Originally made for GoldOS in OS Wars 26. Bash interpreter written in JS, has a fake file system for you to mess with. Currently implemented commands(can be listed with help):

 - cat
 - cd
 - echo
 - help
 - info
 - ls
 - poweroff
 - touch

Other stuff that also works:
 - >
 - >>
 - <
 - &&
 - |
 - ||
 - ;
 - You can provide options to commands and it will behave pretty similar to how they should
